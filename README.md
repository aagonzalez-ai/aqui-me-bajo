# aqui-me-bajo

Proyecto de Programación Móvil.

Consulta el recorrido y las paradas de tu línea de bus. Elige dónde quieres bajarte y recibe un aviso cuando estés cerca: «Prepárate para bajar».

## Primer prototipo

Usaremos una línea de ejemplo y simularemos el viaje. El prototipo tendrá cuatro pantallas: Inicio, Lista de paradas, Detalle de la parada y Viaje activo. Desde el detalle podrás abrir la ubicación de la parada en la app de mapas.
